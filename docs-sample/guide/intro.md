# Introduction

This viewer browses a folder of Markdown documents and searches their full
text. It is deliberately small: no editing, no plugins, no sync.

## Why a viewer rather than an editor

Most Markdown applications ship an entire browser engine in order to render
text. This one uses the webview the operating system already provides, so the
installer stays small and startup is immediate.

## Features

- [x] Folder browsing with directory grouping
- [x] Full-text search across every document
- [x] Table of contents from headings
- [x] Syntax highlighting with dual light/dark themes
- [ ] Anything that writes to disk

## Key bindings

There are none beyond the toolbar buttons; the viewer stays out of the way.
